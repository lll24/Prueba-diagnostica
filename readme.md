## 📋 Descripción

Este repositorio contiene la solución de **3 problemas** correspondientes a la prueba diagnóstica de la materia **Lenguaje y Compiladores**. Cada programa aborda conceptos fundamentales como análisis léxico, validación de formatos estándar y algoritmos matemáticos.

---

## 📁 Estructura del Proyecto
Pruebas_diagnostica/
├── problema1.py # Analizador léxico de expresiones aritméticas
├── problema2.py # Validador de notación FEN (ajedrez)
├── problema3.py # Verificador de la Conjetura de Collatz
└── README.md # Este archivo


---

## 🔧 Requisitos

- **Python 3.7** o superior
- No se requieren librerías externas (solo se usa la librería estándar `re` y `os`)
